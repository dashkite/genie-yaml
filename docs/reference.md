# Reference Documentation

This reference outlines the commands, lifecycles, and configuration options available in the Genie YAML preset.

## Commands

### `yaml:build`

Builds the YAML targets by globbing the specified sources, reading their content, parsing the YAML, modifying the extension to match the target preset, and writing the output to the build directory.

### `yaml`

An alias for the `yaml:build` command.

### `yaml:clean`

Cleans the output generated by the YAML build process.

## Lifecycles

### `build`

The `yaml` command hooks into the `build` lifecycle. When `genie build` is executed, it automatically invokes `yaml`.

## Configuration Options

### `yaml.targets`

The preset accepts configuration options within `genie.yaml` under the `yaml` key. The `targets` property defines the environments and their respective build instructions.

By default, the preset configures `browser` and `node` targets.

```yaml
yaml:
  targets:
    browser:
      - preset: "js"
        glob:
          - "src/**/*.yaml"
          - "test/**/*.yaml"
    node:
      - preset: "js"
        glob:
          - "src/**/*.yaml"
          - "test/**/*.yaml"
```
